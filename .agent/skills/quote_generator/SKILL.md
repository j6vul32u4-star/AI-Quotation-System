# 機台報價單生成技能書 (Quote Generator Skill)

## 觸發條件
當已通過 `ALLOWED_SALES_IDS` 白名單驗證的授權業務人員，在 LINE 查詢機台庫存或要求開立客戶報價單時觸發。

> **安全規範提醒**：嚴格遵守 `.agent/rules/quote_safety.md`，全程使用台灣機械業繁體中文術語，且嚴禁揭露 `cost_price`（進貨成本／底價）。若 `is_asking_cost` 為 `true`，必須拒絕提供成本或底價資訊，僅能以標準牌價與授權折扣進行報價。

---

## SOP 標準作業規則

### 1. 【自然語言意圖解析】
從業務人員的 LINE 訊息中精準萃取以下欄位：
- `customer_name`（字串）：客戶名稱（例如：「台積電」、「鴻海精密」）；若訊息中未提供，預設為 `"貴賓客戶"`。
- `keyword`（字串）：機台品號或關鍵字（例如：`"五軸機"`、`"CNC-L200"`、`"立式綜合加工機"`）。
- `qty`（整數）：需求台數；若訊息中未指定，預設為 `1`。
- `is_asking_cost`（布林值）：判斷業務訊息是否試圖套問進貨成本、底價或毛利結構（`true` / `false`）。

---

### 2. 【階梯式折扣計算規則】
依據需求台數 (`qty`) 與機台標準牌價 (`list_price`) 計算優惠價格：
- **購買 1 台**：折扣率 `1.00`（標準牌價 100%）
- **購買 2 ～ 4 台**：折扣率 `0.95`（95 折）
- **購買 5 台（含）以上**：折扣率 `0.90`（9 折）

**金額計算公式（一律四捨五入至整數）**：
- `discount_rate`：依上述階梯取得之折扣率（`1.00`、`0.95` 或 `0.90`）
- `unit_price`（折扣後未稅單價）：`Math.round(list_price * discount_rate)`
- `subtotal`（未稅小計）：`Math.round(unit_price * qty)`
- `tax`（5% 營業稅）：`Math.round(subtotal * 0.05)`
- `total`（含稅總額）：`subtotal + tax`

---

### 3. 【庫存不足與交期預警】
比對庫存表之可用庫存量 (`available_stock`) 與客戶需求台數 (`qty`)，設定 `stock_note`（庫存與交期備註）：
- **若 `available_stock >= qty`**：
  - `stock_note` 標示：`"✅ 現貨充足（庫存 X 台），下單後 7 個工作天內安排出機"`（將 `X` 替換為實際 `available_stock` 數量）。
- **若 `available_stock < qty`**：
  - `stock_note` 醒目標示：`"⚠️ 現貨不足（目前僅剩 X 台），不足台數需排產 45 個工作天"`（將 `X` 替換為實際 `available_stock` 數量）。

---

### 4. 【輸出格式】
必須產出結構化 JSON 供 GAS 生成 PDF 報價單，並同時提供一段**「一鍵轉發客戶版（隱藏折扣率與庫存細節）」**的專業台灣機械業商務文案 (`customer_copy`)：

```json
{
  "intent": {
    "customer_name": "貴賓客戶",
    "keyword": "CNC-L200",
    "qty": 2,
    "is_asking_cost": false
  },
  "quote_data": {
    "customer_name": "貴賓客戶",
    "part_no": "CNC-L200",
    "machine_name": "高速立式車床 CNC-L200",
    "spec": "雙主軸／FANUC 控制器",
    "qty": 2,
    "list_price": 1800000,
    "discount_rate": 0.95,
    "unit_price": 1710000,
    "subtotal": 3420000,
    "tax": 171000,
    "total": 3591000,
    "available_stock": 3,
    "stock_note": "✅ 現貨充足（庫存 3 台），下單後 7 個工作天內安排出機"
  },
  "customer_copy": "【正式報價通知】\n致 貴賓客戶 採購先進：\n感謝貴司詢價，針對「高速立式車床 CNC-L200（雙主軸／FANUC 控制器）」需求 2 台，專案優惠報價如下：\n・專案優惠單價（未稅）：NT$ 1,710,000 / 台\n・未稅合計：NT$ 3,420,000\n・營業稅（5%）：NT$ 171,000\n・含稅總金額：NT$ 3,591,000\n・預計交期：確認訂單後 7 個工作天內安排出機（若遇現貨調度則依排產時程另行通知）。\n詳細規格與正式報價單請參閱附件 PDF，如有任何技術或商務問題歡迎隨時聯繫！"
}
```

#### 「一鍵轉發客戶版」文案規範 (`customer_copy`)：
1. **隱藏內部敏感資訊**：嚴禁出現具體折數（如「95 折」、「0.95」）、具體庫存剩餘台數（如「庫存 X 台」、「僅剩 X 台」）及任何成本字眼。
2. **交期呈現方式**：
   - 現貨充足時：表述為「確認訂單後 7 個工作天內安排出機」。
   - 現貨不足時：表述為「部分現貨可優先安排出機，預訂機台預計排產交期約 45 個工作天」。
3. **語氣與用詞**：採用台灣機械業專業敬語（如「貴司」、「出機」、「排產」、「未稅／含稅總金額」）。
